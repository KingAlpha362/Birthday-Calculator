# Birthday & Age Calculator

A Python console exercise that compares a supplied age with an age calculated from birth month and year.

## ✨ Highlights

- Reads user input and the current date.
- Uses conditional logic to account for a birthday month that has not arrived.

## 🚀 Getting started

Install Python 3, open a terminal in this repository, then run:

```sh
python "app.py"
```

Follow the prompts in the terminal.

## 🗂️ Repository guide

- [app.py](app.py)

## 📝 Project notes

The calculation uses month and year, not the day of birth. The first `exit()` stops execution; later practice snippets in the file do not run in the normal flow.
